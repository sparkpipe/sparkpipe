# Historical Documentation Archive

This directory preserves superseded design notes, phase reports, handoffs,
audits, estimates, validation snapshots, and diagnostic indexes. The files are
kept for provenance and may describe topologies, model names, performance
assumptions, or implementation states that SparkPipe no longer uses.

Nothing in this directory is a current product, architecture, readiness, or
performance authority. Do not use an archived claim to report current behavior
without reproducing it against the current merged source and hardware.

Current documentation is indexed by [`../README.md`](../README.md):

- [`../../ARCHITECTURE.md`](../../ARCHITECTURE.md) defines the selected system.
- [`../../TECHDEBT.md`](../../TECHDEBT.md) lists unfinished implementation work.
- [`../../PERFORMANCE_STATUS.md`](../../PERFORMANCE_STATUS.md) separates retained
  measurements, projections, and target gates.
- [`../MODEL_SUPPORT.md`](../MODEL_SUPPORT.md) defines the current model scope.

Archived files retain their original wording so historical receipts remain
interpretable. Git history remains the authority for when and why each file
changed.
