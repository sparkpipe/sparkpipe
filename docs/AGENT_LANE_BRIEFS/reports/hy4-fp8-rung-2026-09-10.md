# hy4 FP8 numerical rung — 2026-09-10

Rung 2 of the hy4 FP8 lane: the production grouped-dot kernel
(`SparkHy4DotFp8Grouped`, int8 payload x E8M0 bias-127 group-32 scales,
from `modules/hy4_resident_decode_stage/source/spark_hy4_resident_decode_stage_cuda.cu`
linked unmodified as a second TU) driven over every row-aligned FP8
payload+scale pair of the PLACED rank-02 pack, each dot compared against
an independent double-precision CPU expectation at NONZERO positions
(deterministic LCG activations, zero-free; zero expected dots are flagged
and were 0).

573 FP8 pairs of the pack, 4584 sampled dots (8 rows per projection:
experts {0, last} x rows {0, 1/3, 2/3, last}):

- EXPERT (routed, rank-02 = experts 32..47): gate_up_proj + down_proj,
  78 layers, 312 projections, 2496 dots.
- SPINE: shared_experts gate/up/down (237), dense layer-0 mlp (3),
  attention q_a_proj / kv_a_proj_with_mqa / indexer.wk row-aligned pairs
  (21), 261 projections, 2088 dots.
- NOT covered: 259 FP8 tensors whose scale planes are replicated or
  dim1-split rather than row-aligned (o_proj, q_b_proj, kv_b_proj).
  Consuming them needs the scale-row-offset contract of the lazy attach
  path (weightd); they exercise the same kernel with an index offset, so
  they are an attach-milestone acceptance case, not a kernel-numerics
  risk. This is the concrete test case for verifying hy4's attach path
  against main's converged-weights seam (k3 A-0023).

## Verdict

**NOISE-CLASS.** Abs deltas sit at float32 fmaf-accumulation scale
(<= 1.11e-06 across 4584 dots, including 6144- and 18432-wide rows);
relative deltas are epsilon-scale at the median and rise only through
cancellation on near-zero expected dots. No bias-shaped error (a wrong
E8M0 bias would produce O(2^k) outliers), no layer-dependent jump, no
SPINE/EXPERT asymmetry. SparkHy4DotFp8Grouped + E8M0 bias-127 is
numerically sound on real placed-pack bytes at nonzero positions.
