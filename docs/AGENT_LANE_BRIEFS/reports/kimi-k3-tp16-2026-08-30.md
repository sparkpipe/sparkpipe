## Code in this PR (module-local)

1. Head exchange on the device tier (commit 396ade0): the head's cross-rank
   argmax packs (score, token) into one monotone u64 (total-order score
   transform high word, inverted token low) and rides ONE stream-ordered
   U64Max per row; unpack reconstructs (token, score) on the same stream.
   Kills the per-step host TCP round-trip + double staging; TP4 host
   slot-sum stays as the fallback tier. Also makes a TP16 runner
   CONSTRUCTIBLE (tp_collective hard-requirement relaxed to device-tier-
   or-host-tier).
2. Adapter TP16 fix: above SPARK_TP_COLLECTIVE_MAX_STEPS the tp_collective
   parse is skipped when a device collective exists. The generator emits
   TP16 adapter configs WITHOUT tp_collective (by design — the f32 host
   frame tops out at 4 ranks), and the old unconditional parse made every
   TP16 config load die at SCHEMA_ERROR. Tierless degree>4 stays refused.
3. keepalive.sh: optional TILE_K arg passes expert_tile_k through to the
   packer (TP16 builds); default behavior unchanged.
