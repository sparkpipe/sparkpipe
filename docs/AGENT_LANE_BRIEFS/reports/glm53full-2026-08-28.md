since its first fix commit:
1. **ssh argv re-tokenization (the big one):** `ssh host bash -s "a b c"`
   joins args with spaces — the remote bash read `RANKS="0"`,
   `BYTES=1`. Every run "verified" rank 0 against a bytes-test of 1,
   re-pushed it, and exited 0. Fix: `printf '%q'` the args across the
   hop. Also explains the fleet gap the respawn inherited (ranks b-f
   never placed).
2. **stdin-consumption:** an inner ssh/rsync inside a `bash -s <<HEREDOC`
   body consumes the unread remainder of the script itself. Fix: `-n`
   on inner ssh, `</dev/null` on rsync.
Generalized with `--bytes`/`--prefix` so one script serves all three
resolutions.
