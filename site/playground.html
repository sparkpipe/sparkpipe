Context

Full context sends the whole chat with every message until the model's window is full. Compact at the target summarizes the oldest exchanges whenever the chat grows past the target, then sends that summary and the newest exchanges. Compact now does it once. Either way, this browser keeps the full text.

Developer options

With no reply limit a reply may use the rest of the model's context window. An empty temperature uses the model's published sampling; 0 decodes greedily. With a seed, a sampled reply replays token for token on the same deployment. A request still running at its deadline is cancelled.
