Roofline-Anchored Inference Score.

Raw tokens per second cannot compare a 104B active MoE against a 5B flash model, BF16 against FP4, or 16 DGX Sparks against 8 H200s. 01 Rooflines

Three physical bounds

Every step obeys three independent physical lower bounds.

For model M, hardware profile H with N accelerator ranks, batch size B, context length C, and forward-step rows R per sequence (Trows = B · R; R = 1 for plain decode, R = K + 1 for speculative verify, R = L for prefill), any lossless inference engine must satisfy compute, memory bandwidth, and collective network lower bounds.

1.1 Compute Roofline

Tcompute

Tc = (2·Pspine·Trows)/(N·TFspine) + (2·Pexp·Trows)/(N·TFexp) + Fattn/(N·TFbf16)

Matches non-expert spine FLOPs, active routed MoE expert FLOPs, and causal attention FLOPs over effective context Ceff (capped at sparse window Csparse for DSA/CSA2 layers) against precision-specific peak TFLOPS across N ranks.

1.2 Memory Bandwidth Roofline

Tmemory

u(Trows,E,K) = 1 − (1 − K/E)Trows
Tm = (Wspine + Wexperts(u) + Wkv+idx+state) / (N·BWmem)

Streams spine weights once per step, routed MoE experts by the exact coupon-collector union law u(Trows, E, K) (recovering single-token active weights at Trows=1 and full expert pool as batch grows), plus KV cache, sparse indexer scan, sliding-window KV, and recurrent GDN/KDA state.

1.3 Network Collective Roofline

Tnetworkmin

Tnmin = Rops·τhop + Rops·[2(N−1)/N]·(Trows·dh·2B) / BWnet

Zero for single-rank hardware (N=1). For multi-rank tensor parallelism, models with L layers execute at least Rops = 2L full-hidden BF16 all-reduces per step, paying hop latency τhop plus the ring reduce-scatter/all-gather wire floor.

The true overlapped physical floor is Tfloor = max(Tcompute, Tmemory, Tnetworkmin), while the serialized zero-overlap floor is Tserial = Tc + Tm + Tnmin. Their ratio Goverlapmax = Tserial / Tfloor ∈ [1, 3] measures how much headroom compute-communication overlap can unlock: an engine that overlaps collectives with GEMMs surpasses Tserial and approaches 100, while an unoverlapped engine hits a ceiling at 100 / Goverlapmax.

02 Pillars

22.5%×4 + 10%

Five orthogonal pillars and fifteen sub-metrics.

Every real serving workload stresses a different axis of an engine. RAIS v1.1 distributes 90% of its weight equally across four 22.5% core runtime pillars and 10% to Pillar 5 — Operational & Systems Physics (3 sub-metrics per pillar), all 100% physically anchored and vendor-neutral.

P1 · Single-Stream Decode · 22.5%

1a · Short-ctx B1 (C=256) · 10.8%
Plain non-speculative decode (spec=OFF), B=1 at 256 context. Scored as 100 × Tfloor / Tactual.
1b · Long-ctx B1 (C=64K–128K) · 8.1%
Plain decode at 64K–128K context (capped to served context), exposing KV-scan and sparse-indexer bandwidth overhead.
1c · Tail Jitter (p50/p99 ITL) · 3.6%
Inter-token latency smoothness on the B1 stream: 100 × min(1, ITLp50 / ITLp99).

P2 · Speculation · 22.5%

2a · Acceptance Quality (α) · 10.8%
Mean committed tokens/round α = E[A] + 1 across prose, code, and edit, normalized to αref = 4.0: 100 × min(1, max(0, α − 1) / 3).
2b-i · B1 Verify & Draft Efficiency (1/V) · 7.2%
Verify overhead VB1 = α / (TPSspec / TPSnospec) at K ∈ [4, 16]. Scored as 100 × min(1, 1/VB1) when active, else 0.
2b-ii · B8 Batched Verify Efficiency (1/V) · 4.5%
Batched speculative verify efficiency at B=8: 100 × min(1, 1/VB8) when enabled, separating drafter quality (α) from kernel verify cost (V).

P3 · Batch & Concurrency Scaling · 22.5%

3a · Interactive Batch (B=4, 8, 16) · 9.0%
Equal average across B ∈ {4, 8, 16} against Tfloor(B, 256) with a per-stream SLA ≥ 0.25 × TPSB1; SLA misses scale proportionally.
3b · High-Concurrency Saturation (B=32, 64) · 8.1%
Equal average over B ∈ {32, 64}. Unsupported or capacity-capped batches are scored flat at the highest working smaller batch's aggregate tok/s against B's roofline.
3c · Long-Context Batch (B=8 @ 32K–64K) · 5.4%
Concurrent 8-stream decode at 32K–64K context against Tfloor(8, C), testing multi-sequence KV pressure.

P4 · Prefill & Multi-Turn Agent Loops · 22.5%

4a · Interactive Cold Prefill (8K) · 7.2%
Cold uncached 8,192-token prompt TTFT against Tfloor,prefill(8192).
4b · Long Cold Prefill (32K / 128K+) · 8.1%
Cold uncached 32K (40%) and 128K (60%, capped to served context) prefill against the exact compute/memory/network prefill floor.
4c · Multi-Turn Prefix & State Reuse TTFT · 7.2%
Warm follow-up turns (8K+128 at 40%, 100K+128 at 60%) scored against delta prefill floor Tfloor,warm(Cprefix, 128). Cold recomputation collapses near 0.

P5 · Operational & Systems Physics · 10.0%

5a · Cold Boot / Model Swap Efficiency · 5.0%
Anchored to NVMe sequential read floor Tbootfloor = max(1 s, Wrank / BWNVMe). Scored as min(100, 100 × Tbootfloor / Tcold_boot); unmeasured = 0.
5b · Usable KV Memory Efficiency · 3.0%
Anchored to free RAM floor Mfree = max(1 GiB, RAM − Weights − OS reserve). Scored as min(100, 100 × Musable_kv / Mfree); unmeasured = 0.
5c · Batch-Size Bit-Invariance · 2.0%
Deterministic B=1 short prompt (temperature=0, spec=OFF) run as lane 0 of a mixed B=8 batch. 100 if bit-exact, else 0 — separate from INVALID gates.

Alongside standalone RAIS, every scorecard reports Base Roofline R = (P1 + P3 + P4) / 3 (unchanged pure non-speculative kernel efficiency), speculation tuple (α, 1/VB1, 1/VB8), display-only Stack Badges (Zero-NVIDIA NVRM + SKL CUDA 13.0 Apple Metal 4.0 — zero impact on numeric score), and fleet-weighted aggregates across all 19 canonical models (Tier 1 = 55%, Tier 2 = 25%, Tier 3 = 20%).

05 Integrity

Hard binary gates

Speed without bit-exact fidelity is marked INVALID.

Every certified RAIS run evaluates four binary correctness gates alongside throughput. Passing all four yields VALID; any single failure sets certified_rais = null and marks the run INVALID; imported partial receipts without the full gate suite are marked UNVERIFIED. Batch-size bit-invariance (5c) is scored separately inside Pillar 5 (+2.0 pts) so non-deterministic engines still receive a valid score while deterministic engines earn full credit.

Gate Verification Condition On Failure
prose_exactGreedy (temperature=0) output with speculation ON matches speculation OFF bit-for-bit on the prose prompt.INVALID
code_exactGreedy output with speculation ON matches speculation OFF bit-for-bit on both code and edit prompts.INVALID
prefix_exact (Gate GX)Greedy output on a warm cached multi-turn prefix (8K + 128) matches a cold uncached run of the exact same prompt bit-for-bit.INVALID
errors == 0Zero HTTP 5xx failures, transport drops, OOMs, or GPU Xids across all supported workloads (capacity rejections above max_sequences trigger flat-cap scoring rather than invalidation).INVALID

06 Reproduce

Any OpenAI endpoint

Run RAIS on your own inference engine.

The reference runner talks standard OpenAI /v1/chat/completions and works against SparkPipe, vLLM, SGLang, TensorRT-LLM, or any OpenAI-compatible server. Compare two engines on identical hardware with a single command.

RAIS v1.1 CLI · Fast Hill-Climb & Cross-Engine Comparisonshell
rais-bench \
  --base-url http://127.0.0.1:8000 \
  --model glm-5.3-flash \
  --tier fast \
  --hardware 16x-gb10-1x100g \
  --engine sparkpipe \
  --stack-badge "Zero-NVIDIA NVRM + SKL" \
  --cold-boot-s 8.4 \
  --usable-kv-gib 72.0 \
  --spec-toggle speculation \
  --output rais_results.jsonl \
  --score

rais-score score rais_results.jsonl \
  --hardware 16x-gb10-1x100g \
  --format html-data \
  --output rais-data.json

rais-score compare sparkpipe.jsonl vllm.jsonl \
  --hardware 16x-gb10-1x100g \
  --label-a SparkPipe \
  --label-b vLLM
